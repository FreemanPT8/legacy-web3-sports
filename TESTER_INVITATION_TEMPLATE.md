## Instruções de Primeiro Acesso

**Para incluir no email ou como página separada:**

### 1. Registo
- Clica em "Sign Up"
- Preenche email, username e password
- Confirma (não é necessário email de confirmação)

### 2. Perfil Inicial
- Adiciona uma bio (+25 XP!)
- Escolhe a tua sport role (+19 XP!)
- Adiciona foto de perfil (opcional)

### 3. Primeiros Passos
- **Explora o Dashboard:** Vê o teu progresso de XP
- **Visita a Educação:** Começa lições para ganhar XP
- **Junta-te ao Fórum:** Participa em discussões
- **Completa Missões:** 3 missões diárias disponíveis

### 4. Sistema de XP
- Completa lições: 7-33 XP
- Lê artigos: 5-33 XP
- Participa no fórum: até 25 XP/dia
- Mantém streak de 7 dias: 222 XP!

### 5. Unlocks por XP
- 99 XP → Editar perfil
- 369 XP → Ler posts do fórum
- 444 XP → Comentar e interagir
- 555 XP → Criar tópicos
- 3333 XP → Hall of Fame

### 6. Reportar Problemas
Quando encontrares um bug, envia:
- Descrição do problema
- Passos para reproduzir
- Screenshot (se possível)
- Browser e dispositivo usado
